# bdd-playwright-automation-framework

## Overview
This project is a skeleton for a BDD test automation framework using Maven, Playwright Java, Cucumber, JUnit, Page Object Model, Extent Report, and Log4j.

## Structure
- `src/main/java/com/example/pages`: Page Object classes
- `src/main/java/com/example/utils`: Utility classes
- `src/test/java/com/example/stepdefinitions`: Step Definitions
- `src/test/java/com/example/hooks`: Hooks for browser, reporting, screenshots
- `src/test/java/com/example/runners`: JUnit Test Runner
- `src/test/resources/features`: Cucumber feature files
- `src/test/resources/config`: Configuration files
- `src/test/resources/extent`: Extent Report config
- `src/test/resources/log4j`: Log4j config

## Getting Started
Add your implementation code and dependencies in `pom.xml`.
